What the columns mean
VORP
Draft on this one. A winger can outrank a centre who rates higher, because centres are deeper.
ADP
Where the player typically goes.
Gap
ADP rank minus value rank. Positive means he is sliding — you can wait. Greyed out for players whose value is negative, where a big gap is noise rather than a bargain.
Δ
Places moved since the draft started, as positions drain and replacement levels shift. Blank until you start marking picks.

Replacement Level

Gap is where a player is going minus where his value says he should — positive means the room is letting him slide. Without a real ADP file it is measured against last season's finish, interleaved by position, which is a model of how rooms draft rather than a record of how they did.

Ranked by value over replacement, recomputed from who is still available and how many slots are still to fill. If the league drafts a position in value order the number does not move — it shifts when picks deviate from it, which real drafts do constantly. Picks are saved in this browser, so a refresh mid-draft loses nothing.
